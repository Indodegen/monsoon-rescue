Monsoon Rescue is a 2D canvas game about piloting a small rescue boat through a monsoon storm: pick up stranded sailors, bring them to the lit dock, dodge drifting debris and lightning, and spend the gold you earn on engine, capacity, hull, lightning-rod and lantern upgrades between five ever-wilder storm fronts.

## Run it
```sh
node serve.ts
```
(then open http://localhost:8080)
